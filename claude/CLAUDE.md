# 個人設定

## コミュニケーション
- 常に日本語で応答する
- コミットメッセージは日本語で記述する
- コードコメントは日本語可（ただし変数名・メソッド名は英語）

## コードレビュー方針
- 可読性・保守性を最優先
- 命名の分かりやすさ、メソッドの単一責任、読みやすい構造を重視
- パフォーマンスやセキュリティの問題も指摘する

## Git運用
- コミットは機能単位で細かく分ける
- コミットメッセージは変更の意図を明確に記述する
- **main ブランチに直接 push してはいけない。必ずブランチを切って PR 経由でマージすること**

## モデル・ツールの使い分け
- 実装・調査・計画・レビューなど実作業を伴うタスクでは、作業前に必ず `task-routing` スキルを起動し、`~/.claude/skills/task-routing/routing.md` の表に従って委譲先(サブエージェントのモデル / Codex)を決める

## テスト方針
- テスト追加は状況に応じて柔軟に判断
- 明示的に指示があれば必ずテストを書く
- 新機能追加時は基本的にテストも追加する
